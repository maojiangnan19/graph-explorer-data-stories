04 / Real vs random

Does structure matter?

We compare the Marvel network with an exact-size directed Erdős-Rényi-style random graph: the same 303 nodes and 1,784 directed edges, with distance and clustering measured on the undirected projection.

The random values come from the existing Week 2 `G(n,m)` analysis. Maximum degree and average distance reuse its saved comparison table; clustering was calculated for that same seeded random graph.

05 / Conclusion + methods

So... Is Marvel a Small World?

The Marvel network has a much higher clustering coefficient than the random comparison (0.307 vs 0.042), while its average distance is similar (2.674 vs 2.592). That combination is consistent with small-world-like structure in this snapshot.

It is not proof that the whole Marvel Universe is a small world: the result describes this Wikipedia network, its undirected projection, and this particular null model.

Methods

Week 1's 303-node, 1,784-edge directed graph is projected to a simple undirected graph for distance, clustering, and path exploration. Degree is the total number of incident directed links before projection. Average distance is computed over the selected hero's reachable component; isolated heroes return N/A - disconnected. The comparison random graph matches node and directed-edge counts using the existing fixed-seed Week 2 analysis.
