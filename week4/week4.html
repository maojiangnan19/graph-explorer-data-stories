01 / Starting point

A network can group itself

Each node is a philosopher's Wikipedia page. A directed edge records a link from one article to another; its weight records repeated links. We project reciprocal directions into one weighted connection so that the question becomes structural: where are ties denser within a group than across groups?

Community is a pattern, not a label.Metadata can help interpret a result, but it is not automatic ground truth.

02 / A working definition

More links inside than out

A network community is a candidate partition with relatively concentrated internal ties. It does not have to match an era, a school, or a philosophical identity. The useful question is whether the partition describes the observed connections better than a random expectation.

03 / Cutting the bridges

Some edges hold regions together

Girvan-Newman removes edges with high edge betweenness: links crossed by many shortest paths. The small schematic below makes the mechanism visible. It is a teaching model, not a calculation imposed on the full philosopher network.

04 / Where should we stop?

Modularity asks “compared to what?”

Modularity Q compares the observed within-group weight with what a graph of similar degree distribution would be expected to place there. A higher Q indicates a structurally sharper partition, not proof of “true” communities.

09 / Takeaway

Communities are evidence to inspect

The philosopher network has regions of concentrated weighted connection. Louvain provides one efficient way to expose them; edge betweenness, modularity, stability checks, and backbone filtering show why the result needs interpretation.

Detected communities are structural descriptions of this Wikipedia-link snapshot, not a definitive map of philosophical traditions.

Methods and data

The page loads the supplied 1,444-node table and 11,135 directed weighted edges. Reciprocal edges are summed into an undirected weighted projection. The explorer computes a browser-side Louvain local-modularity partition and reports weighted modularity; it keeps isolated nodes in the node table while graph views draw linked nodes. Stability runs vary node order, and the backbone is a real-time threshold on projected edge weight.
